# ZYNBYTE — Link Page

A responsive, monochrome link page for ZYNBYTE.

## Files
- `index.html` — page content and social links
- `style.css` — responsive black-and-white design

## Publish with GitHub Pages

1. Sign in to GitHub as `zynbyte-tech`.
2. Create a **public** repository named exactly `zynbyte-tech.github.io`.
3. Upload `index.html` and `style.css` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. Wait for deployment. Your page will be at:
   `https://zynbyte-tech.github.io/`

The page links to:
- Telegram: https://t.me/zynbyteoff
- X: https://x.com/zynbyte
- GitHub: https://github.com/zynbyte-tech

No backend, build step, or paid service is required.
